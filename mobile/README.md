# HEARTBEAT HEAVEN Android App

Native Android app for HEARTBEAT HEAVEN.

## Phase 1
- Home
- Latest Songs
- Search
- Song details
- Audio player
- Lyrics
- Favorites
- Share song

The app consumes the existing HEARTBEAT HEAVEN REST API. It must never contain the Supabase service-role key or Studio admin credentials.

Production API base: `https://heartbeat-heaven.onrender.com`

This directory is intentionally isolated from the existing website so mobile development cannot alter the website runtime.
